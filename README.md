# 🪔 Diwali Sales Data Analysis (Python)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a retail dataset containing Diwali sales transactions. The objective is to analyze customer purchasing behavior, identify key revenue drivers, and generate actionable business insights.

The analysis focuses on understanding **customer demographics, product categories, and regional performance** to support data-driven decision-making.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing on raw sales data
* Analyze customer demographics (age, gender, marital status)
* Identify top-performing states and product categories
* Understand purchasing patterns during festive seasons
* Generate actionable insights for business growth

---

## 📊 Dataset

* Contains customer transaction data during Diwali sales
* Includes features such as:

  * User ID
  * Gender
  * Age Group
  * State
  * Marital Status
  * Product Category
  * Amount (purchase value)

---

## 🛠️ Tech Stack

* **Python**
* **Pandas** (Data Cleaning & Analysis)
* **NumPy**
* **Matplotlib & Seaborn** (Data Visualization)
* **Jupyter Notebook**

---

## 🔍 Key Analysis Performed

* Data cleaning and handling missing values
* Exploratory Data Analysis (EDA)
* Grouping and aggregation using Pandas
* Visualization of trends using bar charts, count plots, and heatmaps
* Customer segmentation analysis

---

## 📈 Key Insights

* Female customers contributed **~60–65% of total purchases**
* Age group **26–35 years** generated the highest revenue
* Married customers showed higher purchasing power
* Top-performing states included **Uttar Pradesh, Maharashtra, and Karnataka**
* Highest sales observed in **Clothing and Electronics categories**
* Festive season significantly boosted consumer spending patterns
